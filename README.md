# Kiss of War Officer Companion — Development

Private development workspace for the Officer Companion.

## Baseline

The application snapshot in this repository is being established from the English Live repository `rogerangliss-byte/KoW-Companion`, branch `main`, commit `e0b85332f006796b7b37529954b8b6b915e45a43` (12 November 2026 inspection).

English Live is the source of truth. This repository is for development and testing only. Do not deploy from here or promote changes to English Live without explicit approval.

The production custom-domain file (`CNAME`) is intentionally not copied, so this private development repository cannot claim the Live domain.

The first planned enhancement is automatic backup and restore. Existing application features and data must be preserved.
